# ❌⭕ Tic-Tac-Toe

A terminal-based **Tic-Tac-Toe** game developed in **C++** that supports two-player, turn-based gameplay. This project recreates the classic game entirely within the command-line interface while demonstrating fundamental C++ programming concepts and game logic.

---

## 📖 Overview

This application allows two players to compete in a traditional game of Tic-Tac-Toe through the terminal. The project focuses on implementing the game's core mechanics without relying on a graphical user interface.

The game includes the following features:

- ❌ Two-player turn-based gameplay
- ⭕ Game board management
- ✔️ Move validation
- 🏆 Automatic win detection
- 🤝 Draw detection
- 💻 Terminal-based interface

---

## ✨ Features

- Command-line (terminal) gameplay
- Two-player local mode
- Automatic win and draw detection
- Prevents invalid moves
- Simple and efficient game logic
- Easy-to-read terminal interface
